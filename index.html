Alat yang Digunakan

Beberapa alat dan bahan utama yang diperlukan untuk membuat kabel LAN.

🔌

RJ45

Konektor yang dipasang pada ujung kabel UTP agar dapat terhubung ke port jaringan.

🛠️

Tang Crimping

Digunakan untuk menjepit dan mengunci kabel UTP ke dalam konektor RJ45.

🧪

LAN Tester

Digunakan untuk memeriksa apakah susunan kabel LAN sudah benar dan terhubung dengan baik.

🧵

Kabel UTP

Media penghantar data yang digunakan untuk menghubungkan perangkat komputer dalam jaringan.

Step by Step

Cara Merangkai Kabel LAN

Berikut langkah sederhana membuat kabel LAN tipe straight-through.

1

Siapkan alat dan bahan

Siapkan kabel UTP, dua buah konektor RJ45, tang crimping dan LAN tester.

2

Potong dan kupas kabel

Potong kabel UTP sesuai kebutuhan kemudian kupas bagian luar kabel dengan hati-hati.

3

Susun warna kabel

Susun kabel menggunakan standar T568B agar urutan warna pada kedua ujung kabel sama.

4

Masukkan ke RJ45

Masukkan delapan kabel ke konektor RJ45 sampai seluruh ujung kabel mencapai bagian depan konektor.

5

Lakukan crimping

Masukkan RJ45 ke tang crimping kemudian tekan dengan kuat sampai pin RJ45 mengunci kabel.

6

Testing menggunakan LAN Tester

Hubungkan kedua ujung kabel ke LAN tester. Jika lampu menyala sesuai urutan 1–8, kabel dapat digunakan.

Standar T568B

Urutan Warna Kabel LAN

Susunan berikut digunakan pada kedua ujung kabel untuk membuat kabel straight-through.

Pin Warna Fungsi
1 Putih-Orange Transmit +
2 Orange Transmit -
3 Putih-Hijau Receive +
4 Biru Data
5 Putih-Biru Data
6 Hijau Receive -
7 Putih-Coklat Data
8 Coklat Data

File Sharing

Cara Sharing File

Setelah kedua laptop terhubung, file dapat dibagikan melalui jaringan LAN.

1

Pilih folder yang ingin dibagikan

Klik kanan folder → Properties → Sharing.

2

Aktifkan File Sharing

Pilih Advanced Sharing kemudian centang Share this folder.

3

Atur permission

Berikan izin membaca atau mengubah file sesuai kebutuhan.

4

Akses dari Laptop 2

Tekan Windows + R kemudian masukkan: \\192.168.1.1 untuk membuka folder yang dibagikan.

Kesimpulan

Kesimpulan Praktikum

Pembuatan kabel LAN menggunakan RJ45, kabel UTP, tang crimping dan LAN tester membutuhkan ketelitian terutama dalam menyusun urutan warna kabel. Setelah kabel berhasil dibuat dan diuji, kabel dapat digunakan untuk menghubungkan dua laptop. Dengan pengaturan IP Address yang sesuai, kedua laptop dapat berkomunikasi dan melakukan sharing file melalui jaringan LAN.
